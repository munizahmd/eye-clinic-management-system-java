# Eye Clinic Management System

## 📌 Description
This project is a Java-based application designed to manage the operations of an eye clinic.  
It allows users to register doctors and patients, manage appointments, and maintain records efficiently.

---

## ✨ Features
- Doctor and Patient Registration  
- Appointment Booking and Cancellation  
- View Doctors, Patients, and Appointment Records  
- Login Authentication System  
- Activity Logging for Key Operations  
- User-Friendly Graphical Interface (GUI)  

---

## 🛠️ Technologies Used
- Java (OOP Concepts: Inheritance, Polymorphism, Abstraction)  
- Java Swing (GUI)  
- MySQL Database  
- JDBC (Java Database Connectivity)  

---

## 🧠 Concepts Implemented
- Object-Oriented Programming (OOP)  
- Database Integration  
- File Handling / Record Management  
- Basic Authentication System  

---

## ▶️ How to Run
1. Clone the repository  
2. Open in NetBeans IDEA or any Java IDE  
3. Configure MySQL database  
4. Run the main class
